# Synthetic draft contract examples

У каждой схемы один положительный и два отрицательных примера. Они не доказывают криптографическую подпись или полномочия. Схемы не опубликованы и не являются работающими API. JSON Schema 2020-12 + format checker; семантические проверки timestamps, idempotency, rights и actual runtime обязательны отдельно.
